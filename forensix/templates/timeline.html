Forensic Timestamp Interpretation Notice

Filesystem timestamps (Modified, Metadata Changed, Accessed, Created) reflect OS storage attributes and do not conclusively prove human user presence. Modern Linux kernels use relatime/noatime, meaning access times may not update on every read. True file creation time (birthtime) availability depends on filesystem capabilities (e.g. ext4, NTFS, APFS). Inode status change (ctime) is never interpreted as file creation. Investigation milestones are software audit logs and are strictly distinguished from evidence timestamps.
