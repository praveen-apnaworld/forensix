Forensic Reality: Missing Optional Metadata is Normal

Unlike mandatory container properties (such as pixel dimensions and image format), EXIF camera details, optical settings, and GPS telemetry are optional application-level tags. Physical cameras only populate fields when configured, and web platforms (social media, messaging services, image editors) routinely strip EXIF headers for privacy and bandwidth conservation. Fields marked Not Recorded in File represent verified absence of data in the file stream—never an extraction malfunction.
